# Обзор архитектуры Bismuth

## Общая структура

Bismuth построен на модульной архитектуре с разделением ответственности между аудио-обработкой, пользовательским интерфейсом и утилитами.

### Основные компоненты

1. **Входная точка** (`src/index.js`)
   - Инициализация приложения
   - Настройка глобального экрана blessed
   - Обработка горячих клавиш

2. **Аудио система** (`src/audio/`)
   - Декодирование и воспроизведение аудио
   - Управление состоянием плеера

3. **Пользовательский интерфейс** (`src/ui/`)
   - Терминальный интерфейс на основе reblessed
   - Компоненты: плеер, вкладки, файловый менеджер

4. **Конфигурация** (`ui-options/`)
   - JSON5 файлы для настройки внешнего вида

## Поток работы

1. **Инициализация**
   - Загрузка конфигурации UI
   - Создание аудио контекста
   - Инициализация компонентов интерфейса

2. **Воспроизведение**
   - Выбор файла через файловый менеджер
   - Декодирование через FFmpeg
   - Воспроизведение через web-audio-js + Speaker

3. **Управление**
   - Горячие клавиши для управления плеером
   - Переключение вкладок
   - Перезагрузка компонентов

## Зависимости

- **reblessed**: терминальный UI
- **@descript/web-audio-js**: аудио контекст
- **fluent-ffmpeg**: обертка FFmpeg
- **speaker**: вывод аудио
- **music-metadata**: чтение метаданных

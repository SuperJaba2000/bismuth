# Руководство пользователя

## Запуск

```bash
npm start
```

## Управление

### Горячие клавиши

- **q** или **Ctrl+C**: выход
- **r**: перезагрузка интерфейса
- **a**: перезагрузка аудио системы

### Навигация

- **Tab**: переключение между вкладками
- **Стрелки**: навигация в списках
- **Enter**: выбор файла/действия

### Воспроизведение

- **Пробел**: play/pause
- **Стрелки влево/вправо**: перемотка (планируется)
- **Колесико мыши**: изменение громкости (планируется)

## Вкладки

### Files
- Просмотр файловой системы
- Выбор аудио-файлов для воспроизведения
- Аудио-файлы отмечены ♫

### Yandex (планируется)
- Скачивание треков через Yandex Music API

### Config (планируется)
- Настройка параметров приложения

## Поддерживаемые форматы

- MP3
- OGG
- WAV
- Другие форматы, поддерживаемые FFmpeg

## Требования

- Node.js >= 16
- FFmpeg (включается автоматически)
- Терминал с поддержкой 256 цветов (не обязательно)

# Конфигурация интерфейса

Конфигурация Bismuth хранится в папке `ui-options/` в формате JSON5.

## Файлы конфигурации

### global.json5
Глобальные настройки интерфейса
- Цвета, шрифты
- Размеры элементов

### player_box.json5
Настройки компонента плеера
- Положение кнопок
- Стили прогресс-бара
- Формат отображения времени

### tab_header.json5
Настройки заголовка вкладок
- Положение и размер
- Цвета активной вкладки

### tab_files.json5
Настройки вкладки файлов
- Стиль файлового менеджера
- Выделение аудио-файлов

## Формат JSON5

JSON5 позволяет:
- Комментарии
- Необязательные кавычки для ключей
- Запятые в конце

Пример:
```json5
{
    // Комментарий
    width: 50,
    height: 10,
    style: {
        fg: 'yellow'
    }
}
```

## Изменение конфигурации

1. Отредактируйте соответствующий .json5 файл
2. Перезагрузите UI клавишей 'r' 
   Или перезапустите приложение
